# 최종 슬라이드 구성

2026년 10월 12일 개정 사항을 반영한 한국어 강의 자료이다.

## 10월 13일 장표 구성

원본은 build_pptx/slides_data.py의 18개 10분 블록이다. 첫 8블록은 보고서·기획서 무료 웹 실습, 9번째는 10분 휴식, 10-15블록은 예산·WBS·Gantt·최종 검수와 재사용, 16번째는 강사 관찰 시연, 마지막 2블록은 연속 휴식과 선택 Q&A다.

모든 장표 하단에 해당 10분 블록의 시간을 표시한다. 블록 안에서 여러 장표를 사용해도 시간을 추가 합산하지 않는다. 수강생 작업은 TXT 복사, AI 대화, 결과 저장, 근거 검수로 완료한다. 워크북 수식 수정과 데스크톱 폴더 작업은 필수 참여 단계가 아니다.

보고서와 기획서의 미리보기는 현재 가상 자료에서 만든 실제 PDF 첫 페이지다. Gantt 미리보기는 현재 배포 워크북의 일정 시트다. 화면 예시는 특정 서비스의 실측 응답이나 실제 행정 실적으로 표시하지 않는다.

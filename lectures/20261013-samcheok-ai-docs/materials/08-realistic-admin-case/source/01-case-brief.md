# 취업역량 지원사업 운영 개요
교육용 가상 자료입니다. 실제 기관·사업·사람·기업의 정보가 아닙니다.

문서번호 DWC-2026-0930-01 / 작성 행정지원팀 / 보고 기준 2026년 9월 30일 / 검토 센터운영책임

## 보고 목적과 결정 사항
동해여성성장지원센터는 9월 운영 결과와 10월 문서업무 개선 시험안을 검토한다. 수료 인원과 취업확인 인원은 늘었지만 최초응답시간도 증가했다. 사업의 성과와 행정 처리의 부담을 함께 보고하여, 시험 범위와 담당 역할에 대한 승인을 받는 것이 이 문서의 목적이다. 결과가 좋아 보이도록 서로 다른 지표를 합산하지 않는다.

## 운영 범위
사업은 사무행정, 디지털문서, 회계기초, 고객지원, 온라인운영, 취업준비의 6개 과정으로 구성한다. 매월 과정별 등록은 30명이고 총 등록은 180명이다. 오전, 오후, 혼합 시간대와 읍내권, 해안권, 내륙권을 사용한다. 모든 구분은 합성 데이터이며 실제 지역별 성과를 의미하지 않는다.

상담은 등록자당 초기상담, 문서지도, 진로점검, 사후관리의 4단계를 기록한다. 방문, 전화, 온라인 채널을 혼합한다. 한 사람에게 여러 번 상담하므로 상담 건수를 사람 수로 표시하면 안 된다. 기업 추천도 중복 추천이 가능한 사건 단위 기록이다.

## 집계 원칙
수료율은 해당 월 수료 인원 / 해당 월 등록 인원이다. 취업확인율은 취업확인 인원 / 해당 월 수료 인원이다. 설문 응답률은 응답자 / 등록자이다. 평균 응답시간은 월별 상담 사건의 최초응답시간 평균이다. 두 월의 참여자를 고유한 개인 수처럼 합산하지 않는다.

## 보고와 승인 흐름
상담1팀은 운영 현황과 후속안내를 기록한다. 상담2팀은 개선안과 가정 표현을 검토한다. 교육운영팀은 과정과 안내문을 관리한다. 행정지원팀은 자료 버전, 지표, 집행 전표를 확인한다. 센터운영책임은 시험 범위와 업무시간 배정을 결정한다. 실제 직위나 실명은 이 자료에 포함하지 않는다.

## 원자료 관리
핵심 사실 묶음은 원자료에서 계산한 발췌본이며 원자료를 삭제한 것이 아니다. 등록ID, 집행ID, 업무ID로 추적하고 문서에 제목, 기간, 버전, 출처를 남긴다. 응답 지연 원인, 장기 고용유지율, 실제 시간절감 효과, 예산 변경의 허용 범위는 확인 필요로 남긴다. 기대효과는 목표, 업무시간은 배정안으로 구분한다.

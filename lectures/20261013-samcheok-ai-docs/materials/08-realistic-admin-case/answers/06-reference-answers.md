# 9월 운영 결과 보고 참고답안
교육용 가상 자료입니다. 실제 기관·사업·사람·기업의 정보가 아닙니다.

## 운영 현황과 검토 요청
9월 등록 180명 중 144명이 수료해 수료율은 80.0%였다. 전월의 126명, 70.0%보다 18명, 10.0%p 증가했다. 취업확인은 54명으로 전월 45명보다 9명 증가했으며, 수료 인원 대비 취업확인율은 37.5%였다. 이 값은 장기 고용유지율이 아니다.

상담은 총 720건이며 평균 최초응답은 3.70시간이다. 상담 건수는 중복 상담을 포함한다. 응답시간 증가의 원인은 아직 확인되지 않았다. 안내문 중복과 자료보완 요청을 조사 항목으로 남긴다.

예산 18,000,000원 중 12,360,000원을 집행했으며 잔액은 5,640,000원이다. 설문은 등록자 180명 중 160명이 응답해 응답률 88.9%, 평균 만족도 4.10/5점이었다.

다음 조치로 지표 정의와 공통 안내문을 정리하고, [가정] 2개 팀이 4주간 가상자료로 문서 개선을 시험하는 안을 제안한다. 센터운영책임에게 시험 범위, 담당 역할, 기존 업무시간 배정, 지표 측정 방식의 검토와 승인을 요청한다.

## 근거 대응
등록·수료·취업확인은 participants.csv, 상담과 최초응답은 counseling.csv, 설문은 surveys.csv, 집행은 budget-ledger.csv, 개선 논의와 승인 요청은 회의록에 근거한다. 원인과 시간절감 효과, 실제 승인 여부는 제공 자료로 확인되지 않는다.


## 실행 기획서 참고 구조
목적은 반복 작성과 수치 검수 절차의 개선 시험이다. 대안 A는 무료 웹과 공통 사실 묶음, 대안 B는 로컬 폴더와 데스크톱 작업이다. 기본 시험은 A를 제안한다. 4주, 2개 팀, 합계 주당 4시간 이내를 가정으로 표시한다. 추가 유료 결제와 신규 채용은 제외한다. 예산 잔액을 승인액으로 바꾸지 않는다.

1주차에는 지표와 서식, 2주차에는 초안과 검수, 3주차에는 재사용과 측정, 4주차에는 결과와 지속 여부를 검토한다. 완료 기준은 파일 존재만이 아니라 수치 대조와 승인 기록을 포함한다. 목표는 원인이나 성과가 아니라 시험에서 확인할 가정이다.

## 일정 지연 참고답안
T08 종료가 10월 30일로 지연되면 T10의 10월 28일 시작과 충돌한다. T10이 뒤로 이동하면 T11, T12, T13 등 의존 경로를 다시 검토한다. 서로 독립적인 T09까지 자동으로 같은 기간만큼 늦출 이유는 없다. 원본 날짜를 유지한 비교표에서 충돌, 변경 제안, 담당 승인 필요를 구분한다.

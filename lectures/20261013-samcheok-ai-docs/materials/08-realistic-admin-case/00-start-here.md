# 무료 웹 실습 시작 안내
교육용 가상 자료입니다. 실제 기관·사업·사람·기업의 정보가 아닙니다.

## 준비
ChatGPT 또는 Claude 웹 계정 하나에 로그인한다. 다운로드한 ZIP을 먼저 압축 해제한다. GitHub 계정, 데스크톱 설치, 유료 결제, 별도 문서 준비는 필요 없다.

## 기본 실습 순서
1. `01-facts-to-paste.txt`를 열고 전체 내용을 복사한다.
2. `02-prompts.txt`에서 실습 1 요청문을 골라 같은 메시지에 붙인다.
3. 결과를 `outputs/report.txt`에 저장하고 수치·분모·요청을 확인한다.
4. 같은 사실 묶음과 실습 2 요청문으로 기획서를 만든다.
5. `03-wbs-to-paste.txt`와 실습 3 요청문을 함께 넣어 원본 24행과 지연 영향을 검토한다.
6. `04-review-to-paste.txt`, 핵심 사실, 실습 4 요청문을 함께 넣고 오류와 수정본을 확인한다.
7. 최종 보고서, 기획서, 검수표, 안내메일을 저장한다. AI 응답은 반드시 사람이 대조한다.

## 원자료 선택 경로
파일 업로드가 가능하면 `source`의 PDF와 `data/admin-workbook.xlsx`를 참고할 수 있다. 업로드를 사용할 수 없어도 핵심 사실 묶음에는 필수 실습 근거가 모두 들어 있다. 전체 데이터는 업무의 맥락과 독립 검수를 위해 제공한다. 수천 행을 매 요청마다 다시 붙이지 않는다.

## 한도가 나타나면
이미 만든 결과를 먼저 저장한다. 준비된 다른 웹 계정이 사용 가능하면 핵심 사실과 현재 초안만 옮긴다. 두 서비스 모두 제한되면 `answers/06-reference-answers.pdf`와 검수표를 열어 직접 오류를 표시하고 최종본을 완성한다. 반복 재시도, 계정 다중 생성, 유료 결제는 실습의 필수 단계가 아니다.

## 제출 기준
보고서에는 보고 기간, 핵심 수치, 미확인 원인, 다음 조치, 승인 요청을 포함한다. 기획서에는 대안, 담당, 일정, 완료 기준, 예산 제약, 가정 표시를 포함한다. 마지막에 본인이 확인한 숫자 3개와 아직 확인할 사항 1개를 남긴다.

## 파일 설명
`source`는 충분한 맥락이 있는 가상 행정 문서, `data`는 원자료와 수식 연결 워크북, `answers`는 참고답안, `outputs`는 본인의 결과 저장 폴더다. 참고답안은 교육용으로 작성했으며 특정 무료 모델의 실제 응답을 보장하지 않는다.

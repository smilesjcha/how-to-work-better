## 자료와 결과 보장

하나의 가상 기관인 동해여성성장지원센터의 취업역량 지원사업을 사용한다. 2개월 참여 등록 360행, 상담 1,440행, 만족도 응답 320행, 예산 집행 60행, 기업 연계 36행, 4주 WBS 24행을 연결한다. 사람 이름, 연락처, 실제 기업명은 포함하지 않는다. 모든 문서에 교육용 가상 자료 표시를 남긴다.

원자료의 양은 충분히 제공하되, 무료 실습에서는 검증된 핵심 사실 묶음 하나만 입력한다. 보고서와 기획서 각 한 번, 최종 검수 한 번을 기본 요청으로 권장한다. 요청 횟수는 사용 가능량을 보장하는 수치가 아니다. 한도가 나타나면 이미 생성한 결과를 저장하고 참고답안과 검수표로 같은 결과물을 완성한다. 다른 서비스는 자신의 계정이 준비되어 있고 사용 가능한 경우에만 선택한다.

## 배포

전체 강의 패키지에는 PPTX, PDF, 강사 운영표, 실습 자료, 빌드 원본을 포함한다. 실습 전용 ZIP에는 시작 안내, 핵심 사실, 요청문, 원자료, 참고답안만 넣는다. GitHub에 올리는 자료에는 이메일 초안, Zoom 참가 암호, 원문 이메일, 강사 행정서류를 포함하지 않는다. Zoom 정보는 김미영 상담사님께 보낼 임시저장 이메일에만 넣는다.

장표의 시간은 10분 블록 단위로 표기한다. 블록의 여러 장표가 동일 시간대를 공유하며, 개별 장표에 임의의 1분 배정을 만들지 않는다.

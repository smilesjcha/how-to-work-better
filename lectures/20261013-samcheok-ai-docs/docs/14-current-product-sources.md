# 10월 12일 확인한 제품 근거

무료 웹 실습은 일반 대화와 복사·붙여넣기를 기본 경로로 설계한다. 파일 업로드와 계정별 기능은 선택 사항이며 고정 요청 횟수나 무제한을 약속하지 않는다. 제품의 접근 권한, 배포 상태, 사용량 안내는 강사 계정에서 확인한다.

- [Claude 사용량과 대화 길이](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work): 대화 길이, 모델, 기능에 따라 사용량이 달라지며 Claude의 여러 제품 화면에서 사용량이 공유된다.
- [Claude 무료 시작 안내](https://support.claude.com/en/articles/8114491-get-started-with-claude): 무료 계정에도 사용량 제한이 있으며 상황에 따라 이용 가능한 메시지 수가 달라질 수 있다.
- [Claude Code Desktop 시작](https://code.claude.com/docs/en/desktop-quickstart): 로컬 프로젝트 폴더를 사용하는 Code 탭과 구독 요건을 확인했다.
- [ChatGPT Desktop](https://learn.chatgpt.com/docs/app): 데스크톱의 ChatGPT와 Codex 작업 경로를 확인했다.
- [ChatGPT Work와 Codex 플랜](https://learn.chatgpt.com/docs/pricing): Free를 포함한 플랜 안내와 배포 조건이 있다. Codex 전체를 유료 전용이라고 설명하지 않는다. API 결제와 구독 사용량을 혼동하지 않는다.

이번 참고답안은 가상 원자료로 제작한 교육용 예시이다. 특정 무료 웹 모델의 실측 출력이라고 표시하지 않는다. AI 효과에 대한 실측 성과는 제공되지 않았으므로 수료·취업 지표 변화를 AI 도입 효과로 설명하지 않는다.

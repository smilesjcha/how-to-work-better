# 최종 배포 검수 기록

검수일 2026-10-12. 교육용 가상자료만 사용했다.

## 강의와 장표

PPTX 54장과 PDF 54페이지의 개수 및 무결성을 확인했다. 14:00부터 17:00까지 18개 10분 블록이며 총 180분이다. 강의 80분, 휴식 10분, 강의 70분, 휴식·선택 Q&A 20분이다. 16:30-16:40의 데스크톱 예시는 강사 관찰 시연이며 학생 유료 결제와 설치는 필수가 아니다.

LibreOffice PDF 변환과 Poppler 렌더를 수행했다. 전 장표를 이미지로 확인했고, 자동 검사에서 텍스트 505개 대상이 일치했다. 텍스트 상자 넘침, 캔버스 이탈, 불일치는 각각 0개였다. 다운로드 링크는 최종 GitHub 배포 페이지로 연결한다.

## 실습 원자료

등록 360행, 상담 1,440행, 설문 320행, 집행 60행, 기업 연계 36행, WBS 24행으로 총 2,240행이다. 등록ID 연결, 월별 등록·수료·취업확인 집계, 상담과 설문 평균, 예산 집행 합계를 대조했다. 실제 사람의 이름·연락처 및 기업 내부정보는 없다.

9월 수료율은 144/180=80.0%, 취업확인율은 54/144=37.5%, 설문 응답률은 160/180=88.9%다. 집행액 12,360,000원과 잔액 5,640,000원을 확인했다. 4주 개선 시험과 KPI는 승인 전 가정이며 실측 AI 효과가 아니다.

## 워크북과 문서

워크북 8개 시트의 집계 수식을 재계산하고 오류값이 없는 것을 확인했다. 8개 시트의 표본 영역 렌더를 모두 확인했다. T08 종료를 10월 30일로 변경했을 때 T10의 선행 충돌 경고가 나타나고, 예산 입력 변경이 잔액 수식에 반영되는 것을 확인한 뒤 원본 입력을 복원했다. 일정은 예정 구간이지 실제 완료 성과가 아니다.

시작 안내, 원자료 문서, 참고답안, 운영표, 준비 안내, README의 PDF 전 페이지를 렌더해 확인했다. 페이지 밖 텍스트는 없었고 문단의 한 줄만 다음 페이지에 남는 현상을 수정했다. 무료 웹 실습용 사실·WBS·오류 문서 TXT와 한도 발생 시 참고답안 경로를 제공한다.

## 공개 범위

공개 대상 파일 목록을 따로 작성했다. 임시 파일, 원문 이메일, Zoom 참가 정보, 강사 행정서류, 실행 환경의 node_modules는 제외한다. 두 배포 ZIP의 CRC 무결성과 공개 문서의 이메일·Zoom 링크 누출 여부를 검사한다. GitHub 최신 main의 다른 강의 파일을 변경하지 않고 이번 강의만 추가한다.

## 강의 반영 포인트

1. **프롬프트 작성법이 최대 수요(6표)** → 1-3 세션을 C.O.R.E 프레임워크 중심으로 실전형 구성, 실습 프롬프트 템플릿에 그대로 반영.
2. **환각·사실 검증 요구 명시적** (응답 1·5) → 2-5 세션에서 "AI가 지어내는 답 교정법(근거 요청, 확인 필요 표시, 원문 대조)"을 별도 꼭지로 다룸.
3. **보안 인지 평균 2.0로 낮음** → 실습 시작 전 1-4에서 금지 기준을 체크리스트로 명확화(선택이 아닌 필수 통과 절차).
4. **완전 초심자 2명**(Claude 처음, 프롬프트 모름) → 실습 ① 시작을 "복사→붙여넣기→전송" 3단계로 스크립트화, 결과 예시 파일 제공으로 낙오 방지.
5. **숙련자 2명**(파일 첨부 자주, 보안 4점) → 선택 과제(자료 정리 심화)와 시연 파트(MCP/Skills·에이전트)로 흥미 유지.
6. **반복 업무 자동화·에이전트 관심 6표** → 2-3 시연을 "발전 6단계" 서사로 확장하고, 2-4 개인 시나리오와 연결.
7. **노션 활용 요청**(응답 8) → 실습 결과의 Markdown→Notion 붙여넣기 흐름을 실습 ①·②에 포함, 템플릿 4종 제공.
8. **엑셀·보고서·PPT 수요**(응답 4·7) → 시연 파트에서 Excel 인사이트·PPT 구성안을 참여자 업무 맥락(주간 매출, 행사 기획)으로 시연.
9. **실습 환경 '잘 모르겠다' 2명** → 사전 안내문에 브라우저·접속 체크리스트 포함, 강의 시작 시 환경 점검 시간(1-4) 확보.

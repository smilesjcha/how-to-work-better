1. Claude의 답변 우측 상단 복사 버튼 클릭
2. 메모장(또는 Notion)에 붙여넣기
3. 이 폴더에 저장

> Notion을 쓰는 분은 `03_notion_markdown_templates`의 템플릿 페이지에
> 바로 붙여넣어 정리하는 것을 추천합니다.

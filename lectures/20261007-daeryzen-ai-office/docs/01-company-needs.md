# 데어리젠 공개 정보 기반 교육 요구 정의

## 확인된 공개 정보

- 데어리젠은 우유·치즈·발효유 등 유가공품을 생산하는 원주 소재 식품 제조기업이다.
- 공식 판매 페이지는 위생관리와 HACCP 준수, 생산·검사 후 출고를 강조한다.
- 강원특별자치도 수출기업 지원 페이지는 안전·청결·영양을 기업의 핵심 지향점으로 소개한다.
- 2026 강원 지역인재 채용페스타 소개에는 서울우유, 매일유업, GS, 한국야쿠르트, 외식 프랜차이즈 등 다양한 고객사가 기재되어 있다.
- 이메일에는 교육 대상이 생산직이 아니라 사무직 재직자 약 24명으로 명시되어 있다.

## 강의 설계에 사용하는 추론

아래는 공개 정보에 근거한 **교육 설계 가설**이며, 데어리젠의 실제 내부 프로세스라고 단정하지 않는다.

1. 식품 제조업의 사무 업무는 생산·품질·구매·물류·영업·경영지원 간 전달 문서가 많을 가능성이 높다.
2. 위생과 품질이 중요한 업종이므로, AI가 문장을 잘 쓰는 것보다 숫자·기준·원문 근거를 보존하는 검수 습관이 중요하다.
3. 여러 고객사와 제품군을 다루는 조직에서는 회의 메모, 이슈 보고, 요청 메일, 주간 현황 요약처럼 반복되는 문서가 자동화의 안전한 첫 대상이 될 수 있다.
4. 외부 AI에 실제 고객명, 레시피, 원가, 불량률, 계약조건을 넣지 않는 보안 경계가 먼저 필요하다.

## 이번 강의에서 다루지 않을 것

- 데어리젠 내부 시스템과 직접 연결하는 자동화.
- ERP, MES, QMS, 그룹웨어에 대한 실제 쓰기 작업.
- 실제 품질·생산·고객 데이터를 외부 AI에 업로드하는 실습.
- 코딩, API 키 발급, 브라우저 확장 프로그램 설치.

이 항목들은 회사의 보안정책과 시스템 환경을 별도로 확인한 뒤 후속 진단·구축 과제로 다루는 편이 안전하다.

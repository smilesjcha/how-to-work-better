# 참고 레포 벤치마크와 적용 결정

## 결론

세 레포를 모두 참고하되 역할을 분리한다.

| 참고 대상 | 참고 여부 | 가져올 것 | 가져오지 않을 것 |
| --- | --- | --- | --- |
| `llm-agent-and-workflow-automation` | 적극 참고 | 최신 PPT 디자인 토큰, 콘텐츠 하네스, 한 장 한 역할, 성공 신호·복구 경로, 보고서·문서 실습 구성 | 5주 과정의 코딩·Agent·LangGraph·CLI 설치 실습, 200장 이상 분량 |
| `ai-native-pm` | 개념 구조 참고 | `context/`, 프로젝트 지도, 단일 원본, 의사결정 기록, 템플릿·평가 기준 분리 | PM 전용 PRD 계층을 모든 직군에 그대로 강요하는 방식 |
| `ax-lecture` | 콘텐츠 골격 참고 | 메모→보고서, 문제→기획서, 상사 관점 검수, 무료 계정·복사/붙여넣기 운영 | 삼척 180분 시간표와 범용 사례를 그대로 복사하는 방식 |

## 최신 PPT 구조 벤치마크

`llm-agent-and-workflow-automation/design-system/ppt/cha-sungjae-lecture/`를 최신 원형으로 본다.

- `design-tokens.json`: 색상·글꼴·간격·도형을 한 곳에서 관리.
- `design-system.mjs`: 빌더가 토큰을 사용하게 해 하드코딩을 줄임.
- `CONTENT_HARNESS.md`: 강의 전체 한 문장, 메시지 우선순위, 장표 역할, 중복 금지 기준.
- `COURSE_QUALITY_VALIDATION.md`: 빌드 성공이 아니라 학습 결과·실습 증거·렌더 품질까지 검증.
- 화면 스타일: 흰 바탕, 검정·회색, 네이비·정보 파랑만 의미 있게 사용, 평면 편집형 구성.

이번 강의는 레포 규약에 맞춰 Python 빌드를 사용하므로 구조는 다음과 같이 번역한다.

```text
design/ppt-design-system.md  -> 시각 토큰의 설명 원본
build_pptx/theme.py          -> 코드에서 쓰는 토큰
build_pptx/layouts.py        -> 레이아웃 컴포넌트
build_pptx/slides_data.py    -> 장표 메시지·노트·시간
build_pptx/build.py          -> 재현 가능한 진입점
```

## AI-Native-PM 구조의 직군 확장

PM용 문서 계층의 핵심은 `PRD`라는 이름이 아니라 **맥락과 결정, 작업 산출물을 분리하고 단일 원본을 정하는 것**이다. 이를 다음처럼 일반화한다.

| 공통 폴더 | PM | 개발자 | 행정·운영 |
| --- | --- | --- | --- |
| `context/` | 사용자, 지표, 정책 | 요구사항, API, 제약 | 규정, 용어, 양식 |
| `inputs/` | 인터뷰, 요청 | 이슈, 로그, 기존 코드 | 접수 문서, 원자료 |
| `work/` | 초안, 검토 | 브랜치, 실험, 테스트 | 작성 중 문서, 검토표 |
| `outputs/` | 승인 PRD, 리포트 | 릴리스, 배포 문서 | 결재 완료본, 공문 |
| `decisions/` | 우선순위·범위 | ADR·트레이드오프 | 결재·예외 처리 이유 |
| `archive/` | 지난 분기 | 이전 버전 | 지난 회차 |

개선 방향은 직군별 폴더를 따로 외우게 하는 것이 아니라 `README.md`에 목적·입력·완료 기준·금지 행동을 쓰고, 각 폴더의 역할을 유지하는 것이다.

## ax-lecture에서 재사용할 내용

- 실습의 고정 리듬: `입력 → 결과 확인 → 한 번 수정`.
- 문서 품질을 요청 구조, 입력 자료, 검수 과정의 결과로 설명.
- 강사가 한 단계 시연한 뒤 참여자가 같은 가상 자료로 따라 하는 방식.
- 상사 관점 검수에서 근거 없는 단정, 누락, 중복, 실행 주체 불명확을 잡는 체크리스트.
- 무료 계정 한도·로그인 문제 시 짝 실습과 강사 화면으로 전환하는 대체 동선.

데어리젠 강의에서는 이를 유제품 제조기업의 사무 업무에 맞는 **가상 생산·품질·영업지원 문서**로 새로 작성한다.

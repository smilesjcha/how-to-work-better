# 월간 운영 리포트 자동화 파일럿 제안

## 1페이지 — 문제와 해결안

### 승인 요청

월간 운영 리포트의 4주 파일럿 착수와 운영·검수 담당 지정을 요청합니다. 데이터 권한·예산·시작일은 승인 전 확정해야 합니다.

### 현재 문제

표 취합, 계산, 문장 작성이 반복되고 초안마다 수치·형식이 달라져 검수 부담이 발생합니다. 먼저 원자료의 지표 정의와 보고 양식을 고정해, 초안의 양보다 보고 가능한 결과물의 품질을 확인하고자 합니다.

### 해결안

CSV 검증 → 지표 계산 → 요약표·보고서 생성 → 사람 검수·승인. 원자료 위치와 산식은 근거표에 보관합니다. 최종 보고서에는 결론·핵심 수치·결정 요청·미확인·다음 행동만 남기고 작성 대화는 분리합니다.

### 사용자와 범위

- 운영 담당: 자료 업로드·입력 오류 확인·초안 검수.
- 팀장: 조사 범위·담당·기한 승인.
- 첫 버전 제외: 사내 시스템 연결, 자동 결재, 외부 발송, 품질 원인·법규·제품 안전 자동 판단.

## 2페이지 — 실행과 승인

### 파일럿 운영안

월간 CSV 2종, 제품 3종을 대상으로 요약표 1종, 보고서 1종, 검수표를 검증합니다. 지표·양식 정의 후 초안을 만들고, 사용자 검증과 승인 절차를 거쳐 배포합니다. 작업별 담당 역할과 일정은 `wbs-gantt.csv`에 정리했습니다.

### 합격 조건 — 제안 목표

| 항목 | 인수 목표 | 확인 방법 |
| --- | --- | --- |
| 수치 일치 | 불일치 0건 | 원자료 합계·분모와 대조 |
| 필수 지표 | 누락 0건 | 양식 필수 항목 점검 |
| 결과 중심 본문 | 작성 대화 혼입 0건 | 본문에서 지시·수정 이력 확인 |
| 배포 책임 | 승인 전 발송 0건 | 승인 상태·파일 목록 확인 |

### 위험과 대응

계산 오류·원문 미확인은 배포를 보류합니다. 민감 정보가 포함되면 업로드를 중단합니다. 작업 기록·초안·최종본은 분리하고 승인된 결과물만 배포합니다.

### 승인 항목과 남은 확인

대상 업무, 운영·검수 담당, 데이터 권한, 예산, 시작일의 승인이 필요합니다. 필요 자원·예산은 산정 전입니다. 시간 절감 효과는 파일럿 전후 같은 범위의 작업을 실측해 평가합니다.

# 문서 유형별 완성 예시

한빛유업은 가상 회사입니다. 실적은 `01-data/`의 교육용 원자료를 사용했습니다. 파일럿 일정·역할·합격 목표는 제안 예시이며 실제 조직의 확정 계획이 아닙니다.

| 문서 | 먼저 답할 질문 | 파일 |
| --- | --- | --- |
| 데이터 요약표 | 무엇이 변했나? | `data-summary.md` |
| 1페이지 보고서 | 무엇을 결정해야 하나? | `../02-report/expected-report.md` |
| WBS·Gantt | 누가 언제 무엇을 끝내나? | `wbs-gantt.md`, `wbs-gantt.csv` |
| 임원 제안서 2pager | 왜 시작하고 무엇을 승인하나? | `executive-two-pager.md` |
| PRD | 무엇을 만들고 어떻게 검증하나? | `service-prd.md` |
| 운영 대시보드 | 어떤 신호에 어떤 행동이 필요한가? | `dashboard-spec.md` |

`prompts.md`에서 필요한 양식 하나의 요청만 선택해 사용하세요. 모든 양식을 한 번에 만드는 것이 목표는 아닙니다. 장표 115, 133–139에서 각각의 완성 화면을 확인할 수 있습니다. PPT의 표·기간 막대·흐름·텍스트는 편집 가능합니다.

최종 문서에는 결론·사실 근거·필요한 결정 이유·실행 사항을 남깁니다. AI에 요청한 순서, 수정 횟수, 대화 중 합의는 별도 작업 기록으로 분리하세요. 회의록·승인 문서·규정상 보존 대상의 기록을 지우라는 뜻은 아닙니다.

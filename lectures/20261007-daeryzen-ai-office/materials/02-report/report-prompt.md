# 실습 B — 1페이지 보고서 프롬프트

당신은 가상 회사 팀장에게 올릴 교육용 보고서 초안을 작성합니다.

- 목적: B 제품 반품 유형과 B·C 목표 미달 이유를 조사할지 결정받기.
- 입력: `source-card.md`의 확정 사실과 확인 필요 항목만 사용.
- 형식: 제목 → 결론·결정 요청 → 핵심 수치 표 → 확인 필요 → 다음 행동.
- 길이: 600자 안팎. 한국인 사무직이 실제로 읽고 쓴 듯한 짧고 명료한 문장.
- 필수: 기간·단위·분모를 유지하고, 자료에 없는 원인은 `[확인 필요]`로 표시.
- 금지: 새 수치·새 출처·제품 안전성·법규 적합성 판단.
- 담당과 기한이 자료에 없으면 `[담당 확인]`, `[기한 확인]`으로 남기기.

초안 작성 뒤 스스로 완료를 선언하지 말고, 사람이 검수할 질문 3개를 덧붙이세요.

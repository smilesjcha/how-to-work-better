# 다음 회차에도 쓰는 검수 체크리스트

## 입력 전

- [ ] 실제 개인정보·고객정보·미공개 회사 자료가 없는가? 없지 않다면 입력하지 않는다.
- [ ] 파일의 기간·제품·단위를 적었는가? 빠졌다면 원본을 확인한다.
- [ ] 원자료와 지난 초안을 구분했는가? 섞였다면 폴더를 나눈다.

## 계산·근거

- [ ] 행 수와 합계를 원본에서 다시 확인했는가?
- [ ] 비율의 분자·분모와 `%`·`%p`를 구분했는가?
- [ ] 원문에 없는 원인은 `확인 필요`로 표시했는가?
- [ ] 외부 주장에 발행 주체·날짜·원문 위치가 있는가?

## 배포 전

- [ ] 독자가 결정할 내용·담당·기한이 분명한가?
- [ ] 초안과 수정본, 수정 이유를 남겼는가?
- [ ] 사람이 회사 정책·사실·표현을 최종 승인했는가?

# 실습 A — 데이터 요약 프롬프트

아래 두 CSV의 내용만 사용하세요. 가상 회사의 교육용 자료입니다.

1. 월별 판매 수량·반품 건수 합계를 계산식과 함께 표로 쓰세요.
2. 6월 대비 7월 판매 수량 증가율을 계산하세요.
3. 연습용 반품률은 반품 접수 건수÷판매 수량×100으로 정의하고, 6월·7월의 비율과 차이(%p)를 계산하세요.
4. 제품별 7월 목표 달성률과 전체 달성률을 구하세요. 전체는 합계/합계로 계산하세요.
5. 출력은 `지표 / 6월 / 7월 / 변화·계산식 / 확인 필요` 표와 핵심 관찰 2문장, 추가 확인 질문 3개입니다.
6. 자료에 없는 원인·식품 안전성·법규 적합성은 추정하지 마세요.

## 오류가 있으면 다시 요청

방금 결과에서 틀린 수치가 있는지 원본 행별로 재계산하고, 오류 위치·기존 값·수정 값·계산식을 표로 보여 주세요. 원인 문장은 원자료에 근거가 없으면 삭제하고 `확인 필요`로 바꾸세요.
